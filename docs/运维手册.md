# 二游 MMD 模型导航

**线上地址：https://ybslmmd.cn/**（香港轻量服务器，nginx + Let's Encrypt，自动续期）

**按游戏分区 → 列出角色 → 点开是「作者本人的配布页」跳转**。
不在本站下载、不托管、不镜像任何模型文件。

支持两种用法：

| 模式 | 打开方式 | 数据在哪 | 谁能改 |
|---|---|---|---|
| **本地模式** | 双击 `index.html` | 你自己的浏览器 | 只有你，随便改 |
| **服务器模式** | 双击 `启动服务.bat` | `data/published.json` | 你审核后生效，所有人看同一份 |

### 线上服务器速查

```
IP        43.129.82.120        区域 香港（不需要备案）
登录      ssh -i ~/.ssh/OKITA.pem ubuntu@43.129.82.120
代码      /opt/mmd-hub
数据      /opt/mmd-hub/data     备份 /opt/backups（每天 3 点，留 7 天）
服务      systemctl status mmdhub  /  journalctl -u mmdhub -n 50
更新      本地双击「上传网页.bat」（只传代码，不动 data）
```

标题右边有个小徽章告诉你现在是哪种：**「本地」**（灰）或**「在线」**（绿）。


> ⚠️ **两种模式的数据是分开的**，浏览器按「网址」隔离存储。
> 在 `file://` 里加的地址，用 `http://localhost:8000` 打开时看不到，反之亦然。
> 想搬过去：本地模式「数据 → 导出 JSON」→ 服务器模式「页脚 → 导入 JSON」
> （导入服务器要输动态码）。

服务器模式下，**访客提交 → 你点通过 → 立刻对所有人上线**。
站长自己在服务器模式下也能：加游戏分区、加角色、改某条地址的官方/同人、删掉填错的地址
——这些都要先验证动态码，改完直接写进线上数据。

## 普通用户：注册登录 + 收藏同步

访客可以注册一个账号（**只要用户名和密码，不用邮箱手机号**），
收藏就存在服务器上，**换手机、换浏览器都还在**。

### 收藏什么

| 收藏对象 | 怎么收藏 |
|---|---|
| **角色** | 角色卡片右上角的 ★ |
| **单条配布地址** | 角色详情里，每条地址右边的 ☆ |

### 收藏夹

顶栏「**★ 收藏**」打开收藏面板（不再是筛选开关）：

- 顶部是收藏夹切换：每个夹子显示条数，右边「＋ 新建」
- 可以**重命名**、**删除**收藏夹（至少保留一个）
- 收藏时会放进当前选中的收藏夹
- 面板里还有「首页只看收藏」开关，按需要在首页过滤

### 数据同步

- 没登录：收藏只在这个浏览器（localStorage）
- 登录后：自动同步到服务器，另一台设备登录同一个账号就能看到
- 登录时会把本机已有的收藏**合并**进账号，不会丢

### 安全上做了什么

| 项目 | 处理 |
|---|---|
| 密码存储 | PBKDF2-SHA256，20 万次迭代 + 每用户独立盐；**服务器上无法还原明文** |
| 登录票 | HMAC-SHA256 签名，30 天过期，用户名 base64 编码（支持中文名） |
| 防暴力破解 | 同一 IP 一小时错 8 次锁一小时 |
| 防刷注册 | 同一 IP 一小时最多注册 20 个 |
| 收藏内容 | 最多 500 条、30 个收藏夹，字段长度都截断 |

### 用户名规则（防重名）

- **2–20 个字**，只能是中文、字母、数字、`_` `-` `·`，不能有空格
- **不区分大小写**：`Alice`、`alice`、`ALICE` 算同一个人，注册后也只有一个人能登
- **全角半角视为相同**：`Ａｌｉｃｅ` 和 `Alice` 冲突
- **首尾空格自动去掉**，`" alice "` 就是 `alice`
- 登录时用任意大小写都行，显示的是你注册时写的那个
- **保留名不能用**：admin / 管理员 / 站长 / 官方 / root / ybsl / ybslmmd 等，防止冒充

> 忘记密码目前只能由你在服务器上手动删账号（`data/users.json`），
> 站里没有找回流程——因为没接邮箱。

## 管理员登录：动态口令（TOTP）

审核用的是**动态口令**，不是固定密码：

- 标准 TOTP（RFC 6238），和微软 / Google Authenticator 通用
- **6 位数字，30 秒变一次**，被别人瞄到也来不及用
- 登录后换一张 8 小时有效的会话票，期间不用反复输
- 连续输错 8 次，这个 IP 锁 1 小时

### 第一次怎么绑定

启动 `server.py` 时控制台会打印：

```
管理员登录：动态口令（30 秒变一次）
第一次用，请在手机的 Authenticator 里「手动输入密钥」：

    ABCD EFGH IJKL MNOP QRST UVWX YZ23 4567

或者把下面这行整段粘进验证器：
    otpauth://totp/MMDHub:admin?secret=你的密钥...
```

手机装一个 **Microsoft Authenticator** 或 **Google Authenticator** →
「添加账户」→「输入设置密钥」→ 把那串字母（空格不用管）填进去 → 选「基于时间」。
之后点角色审核时会提示你输入当前 6 位码。

### 静态口令是兜底

`data/admin.token` 里那串仍然有效，但**只在本机直连时**（`http://127.0.0.1:8000`，
或者没走隧道/反代）能用。手机丢了、换手机了，用它应急，然后删掉
`data/totp.secret` 重启，会生成新的密钥重新绑定。

## 谁在提交、谁在审核

### 访客怎么提交

顶栏「**⚙ 管理**」→ 里面有两个入口：

| 想加什么 | 在哪填 | 提交后 |
|---|---|---|
| **新游戏分区** | 顶部「申请添加游戏分区」 | 进审核队列 |
| **某分区下的新角色** | 对应分区下面那个输入框 | 进审核队列 |

提交成功后会看到**回执**：

```
✓ 已提交，等站长审核
分区申请：明日方舟　　单号 8ed0b6a99bcf
```

访客看到的界面按钮写的是「提交申请」/「申请」，没有删除按钮。

另外还有个更常用的：点角色 → 抽屉底部「提交一条配布地址」。

### 你这边审核

顶栏「**审核**」→ 输入验证器里的 6 位动态码 → 队列里按类型分开显示：

```
添加新角色申请  在「鸣潮」下
今汐
[✓ 通过并添加]  [✕ 拒绝]

分区添加申请  [新分区]  2 个角色
明日方舟
角色：阿米娅、凯尔希
[✓ 通过并建分区]  [✕ 拒绝]
```

- 分区申请 → 通过后**自动建分区**（随机配色），角色一起加进去
- 角色申请 → 通过后加到对应分区
- 地址申请 → 通过后加到对应角色的官方/同人
- 拒绝 → 移出队列，记进 `rejected.json`
- 审核按钮上会显示待审数量（每 30 秒自动刷新）

### 管理员 vs 访客

「管理」面板是**同一个界面，两种身份**：

| | 你（先点「审核」登录） | 访客 |
|---|---|---|
| 按钮文案 | ＋ 添加 | 提交申请 |
| 效果 | 直接写进线上，立刻生效 | 进审核队列，等你通过 |
| 删除分区/角色 | 有 | 没有 |
| 备份 / 迁移 | 有 | 没有 |

> 你的登录票 8 小时过期。过期后打开管理会变成访客视图（能提交申请但不会直接生效），
> 再点一次「审核」输个动态码就恢复。

### 改名（管理员）

管理面板里，每个分区右上角有「**改名**」，每个角色名右边有个小铅笔「**✎**」。

- 分区改名：只改显示名，`id` 不变，下面的角色和地址都不动
- 角色改名：**地址和收藏会一起迁移**
  - `links[游戏][旧名]` → `links[游戏][新名]`
  - 所有用户收藏里的 `游戏id/旧名` → `游戏id/新名`
  - 不会出现"改完名地址全丢了"或者"收藏点进去是空的"
- 重名会被拒绝（不分大小写、全角半角）

**防重复**：同名分区、同角色名（不分大小写）不会进第二次队列；审核期间已经存在了，通过时会提示。

**口令**：第一次启动 `server.py` 会自动生成，打印在控制台，也存在 `data/admin.token`。
浏览器会记住（localStorage），换设备要重新输。

## 启动

双击 `启动服务.bat`（等价于 `python -u server.py 8000`）。

```
二游 MMD 模型导航 · 带审核的后端
地址    http://127.0.0.1:8000
口令    你的口令   （审核时用）
```

- 同一 WiFi 下别人访问：`http://你的内网IP:8000`
- 想让外网访问：见下面「上线」
- 想换端口：`python server.py 9000`

## 上门店：怎么放到公网

服务器模式需要一台**能一直被访问的机器**。三个选择，由便宜到麻烦：

**1. 家里电脑 + 内网穿透（最快，免费）**
装个 [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/)
或 tailscale funnel，把 `localhost:8000` 映射成一个网址。电脑不关就在线。

**2. 便宜的云服务器（最稳，约 20–40 元/月）**
阿里云/腾讯云 2核2G，装 Python 3，把这个文件夹丢上去，`python server.py 8000 0.0.0.0`。
建议前面挂 nginx 做 HTTPS。

**3. 静态托管 + 换后端（免费，但要改代码）**
Vercel / Cloudflare Workers + KV，把 `server.py` 的逻辑翻译成 JS。
免费额度够用，但我没做，要用得再改。

> 自己电脑 + 内网穿透这条，**电脑一关就下线**，适合先试水。

## 数据备份

`data/` 整个目录就是全部数据，复制走就是备份。
`published.json` 是唯一要紧的——丢了等于所有角色和地址都没了。

建议定期复制一份，或者把这个目录放进 git。

### 导出 / 导入 JSON 在哪

**只在「管理」面板里**，页脚和顶栏都不再放这个入口。

- 服务器模式下，进管理面板要动态码 → 普通访客用不了
- 本地模式下随便用

> 说明白一点：这**不是**防抄袭。数据必须发给浏览器才能渲染，
> 任何人按 F12 → Network → `/api/data` 都能看到全部内容。
> 撤掉入口只是少一个「一键拿走」的按钮，真正的护城河是内容本身——
> 你收集和核对地址花的时间，别人抄走也要花时间重新核对。

## 本地模式（不启动服务器）

双击 `index.html` 也行，功能都在：编辑、管理分区/角色、导入导出 JSON。
区别是数据只存在你这个浏览器里，别人看不到，也没有审核那套。

> ⚠️ `file://` 和 `http://` 是**两个不同的存储域**，数据不互通。
> 切换前先「数据 → 导出 JSON」，换过去再导入。

## 发给别人：一定要用打包脚本

**网页文件里没有任何口令**（`index.html` 是纯前端，登录靠你手输）。
但 `data\` 目录里有两个密钥文件，**直接发整个文件夹就等于把后台送人**：

| 文件 | 泄露后果 |
|---|---|
| `data\totp.secret` | 对方能自己生成永久有效的动态码，直接登进你的站 |
| `data\admin.token` | 同上（本机兜底口令） |
| `data\pending.json` / `rejected.json` | 含访客 IP 和提交内容 |

正确做法：

```powershell
.\打包发布.ps1               # 只发模板（分区和角色保留，地址清空）
.\打包发布.ps1 -IncludeData  # 连你收集的配布地址一起发
```

它会打一个 zip 到桌面，**只包含** 网页、后端、文档、部署脚本，以及一个清空了
地址的 `published.json`。`admin.token`、`totp.secret`、队列、日志、缓存全部排除。

收到包的人第一次启动时，server.py 会**各自生成新的口令和密钥**，
和你的完全独立。我实测过：同一个包在两台机器跑，token 和 secret 都不一样。

> 如果你以前已经发过整个文件夹（含 data\）—— 现在就把
> `data\admin.token` 和 `data\totp.secret` 删掉再重启，换一套新的。
> 已经发出去的那份不影响你，只是旧密钥作废了。

## 安全提醒

- **动态口令 30 秒一换**，被偷看基本没用；静态口令只在本机直连时有效。
- 登录票 8 小时过期，连续错 8 次锁 IP 1 小时。
- 现在走的是 HTTP 明文，**放到公网务必上 HTTPS**（Cloudflare 隧道或 certbot 都会自动给你）。
- 已经做了：地址必须是 http/https、提交频率限制（每 IP 每小时 20 条）、
  重复地址拦截、字段长度限制、`/data/` 目录禁止访问。
